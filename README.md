IT Help Desk Ticketing System

A web-based Help Desk Ticketing System designed to simulate a real IT support environment. This project allows users to submit IT support requests, track ticket status, contact the Help Desk, and view resolved support tickets. It demonstrates practical IT support, customer service, incident management, and technical documentation skills.

 Project Overview

The IT Help Desk Ticketing System was developed as a portfolio project to demonstrate the workflow of a modern IT Help Desk. It provides an organized process for reporting technical issues, recording support requests, managing ticket status, and documenting completed solutions.

The project integrates Google Sites, Google Forms, and Google Sheets to create a simple, no-code Help Desk solution.
